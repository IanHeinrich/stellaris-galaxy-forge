### Added

- A megastructure that stands at its own point in a save, such as a Hyper
  Relay or a Gateway, has Distance and Angle fields on its page. Type a
  value to move it.
- A scenario system lists the ruins and ambient objects its effect block
  places. Each megastructure and ambient object row says whether it comes
  from the initializer or from the file.

### Changed

- A save system with no megastructures shows the Megastructures section,
  with a line on how to add one.

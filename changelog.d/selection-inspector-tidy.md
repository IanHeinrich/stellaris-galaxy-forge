### Changed

- The Inspector's page for several selected systems is reorganised into
  Hyperlanes, Position and Set for all sections. Adding lanes is one
  choice, Every pair or Nearby, with one button that says how many lanes
  it adds. The right-click menu on a selected system uses the same names:
  Link every pair, Link nearby, Cut lanes between them and Isolate them.
- Generate lanes like the game is now ticked by default on the Connect
  and Paint brushes and the Inspector's Nearby choice. If you changed it
  before, your choice stays.

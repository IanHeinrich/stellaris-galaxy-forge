### Added

- A scenario system's page and its planets' pages show what the
  initializer places, in the same sections as a save.
  - Values the game rolls show as ranges.
  - Planets an initializer places a random number of times are one row
    with their count. The system view shows every one the game can
    place, with a dashed ring on those not every game has.
  - Script text shows as the file writes it, in the colours of the
    CWTools extension for VS Code.

### Changed

- The line under a system's name and the Planets header count planets
  only. Moons and asteroids are counted in the System total row.
- The Initializer section has Open file and Show in folder buttons, and
  groups the script, the random galaxy settings and the other keys.
- The Source tab marks the lines an edit changed with a bar at the left.

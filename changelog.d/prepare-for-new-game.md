### Added

- Prepare for a new game, on a scenario's Galaxy page. Choose what a new game
  keeps from the map: empire seats, home starts, fallen empires, marauders,
  guardians, enclaves, primitives, wormhole pairs and system names. Each
  row says what the game does with what you leave out.
  - Faithful keeps everything, Fresh start turns what old empires and
    events made into plain systems, and Bare shell lets each new game roll
    the contents afresh.
  - Hover a row to see its systems on the map.
  - Apply is one step to undo.
- After Open save as scenario, the Galaxy page opens with Prepare for a new
  game ready to use. It is also in the File menu.

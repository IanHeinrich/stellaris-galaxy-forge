### Fixed

- Keys pressed in a dialog stay in the dialog. Tab no longer hides the side
  panel behind it, and number keys and arrows no longer change the map.
- Right-click menus on the map take the arrow keys, so you can pick an item
  with the keyboard. The arrows no longer pan the map while a menu is open.
- Enter answers the Paint a Galaxy question before a scenario opens.
- A star's right-click menu offers "Delete", greyed out, and names the star
  in the reason, where it said "Delete planet" and gave an id.
- Messages about a planet or star name it, such as "Deneb IV #1419 already has
  a habitat", where many gave only its id.
- Submenu items such as "Add planet here" line up with the other menu items.
- The edit pencils in the Empires list line up on empires with no systems.
- The side panel no longer scrolls sideways on a scenario's overview. The row for
  adding a scenario header key fits the panel.

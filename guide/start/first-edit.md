# Your first edit

Galaxy Forge edits a campaign you're playing, or builds a galaxy for a
new one. This page edits a save. To build a new galaxy, see
[Make a scenario](../scenario/make-a-scenario.md).

It works with Stellaris 4.x saves.
[Supported game versions](../reference/versions.md) lists what I've
tested in game.

::: warning Steam Cloud
A save marked "☁" on the Open screen is in Steam's cloud folder. Steam
can put the original back over your edited copy. Read
[Steam Cloud](../safety/steam-cloud.md) before you save.
:::

## Quick start

1. Start the app. If a card asks about game data, leave "Load Stellaris
   game data" ticked and click Continue. The Open screen lists the saves
   and scenarios it found on this machine.
2. Pick a save, press <kbd>Enter</kbd> and choose "Edit as save".
3. Drag a star to move its system. Its planets and fleets move with it,
   and its hyperlanes stay connected.
4. Zoom in until a ring appears around a star. Drag from the ring to
   another system to draw a hyperlane. Press <kbd>Ctrl</kbd>+<kbd>Z</kbd>
   to undo an edit.
5. For a first try, select File → "Save as…" and give the copy a new
   name. Keep the copy in the save's own folder, where the dialog opens,
   so Stellaris lists it.
   Later, <kbd>Ctrl</kbd>+<kbd>S</kbd> saves over the open file and keeps
   the previous one beside it as a [backup](../safety/saving.md).
6. Load the copy in Stellaris with the same DLC and mods, and check your
   edits before you keep playing. See
   [Go back to your campaign](../safety/back-to-campaign.md).

On a Mac, read <kbd>Cmd</kbd> wherever this guide says <kbd>Ctrl</kbd>.

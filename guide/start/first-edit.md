# Your first edit

Stellaris Galaxy Forge edits the galaxy map of a Stellaris save, or a
static galaxy scenario that a new campaign starts from. It works with
Stellaris 4.x saves. I've tested the galaxy map edits in game on 4.4.6
and 4.5. [Supported game versions](../reference/versions.md) lists what
else I've tested.

## Quick start

1. Start the app. It lists the saves and scenarios it found on this
   machine.
2. To edit a campaign, pick a save, press <kbd>Enter</kbd> and choose
   "Edit as save". To make a new galaxy, click "New scenario…", or pick a
   save and click "Open as scenario".
3. Drag a star to move it. Zoom in until a ring appears around a star,
   then drag from the ring to another system to draw a hyperlane.
   <kbd>Ctrl</kbd>+<kbd>Z</kbd> undoes.
4. Press <kbd>Ctrl</kbd>+<kbd>S</kbd>. The previous file stays beside the
   new one as a [backup](../safety/saving.md).
5. Load the save in Stellaris as usual. For a scenario, see
   [Export and play](../scenario/play.md).

On a Mac, read <kbd>Cmd</kbd> wherever this guide says <kbd>Ctrl</kbd>.

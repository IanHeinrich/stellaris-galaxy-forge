# System modifiers <Badge type="info" text="Scenario" />

A system modifier changes the system it is on and what is in it. In a
scenario, you can add one to a system and remove it. The system has it
from the day a new game starts. Adding needs the game data loaded.

## Add a system modifier

1. Click the system on the map. Its page opens in the Inspector.
2. Under Modifiers, click Add modifier.
3. Find the modifier. Type in the box to search by name or effect, or
   pick a category.
4. Click the Add button.

The modifier lasts for good. Press <kbd>Ctrl</kbd>+<kbd>Z</kbd> to take
it out again.

The list has the modifiers the game's scripts put on a system, your
enabled mods' included, and any the scenario already has. A modifier
the system already has shows Has it. The turbulent nebula modifier isn't
in the list, because it comes with the nebula.

## Remove a system modifier

Click the ✕ on the modifier's row. <kbd>Ctrl</kbd>+<kbd>Z</kbd> puts it
back.

A row marked From the file can't be removed here. Galaxy Forge doesn't
edit how the scenario wrote it, such as a modifier that lasts some days.

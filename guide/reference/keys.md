# Keyboard shortcuts

On a Mac, read <kbd>Cmd</kbd> wherever this guide says <kbd>Ctrl</kbd>.

## File

| Key | Does |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Open screen |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>O</kbd> | Open any file |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | Save as |
| <kbd>Ctrl</kbd>+<kbd>W</kbd> | Close the file |

## Edit

| Key | Does |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Undo |
| <kbd>Ctrl</kbd>+<kbd>Y</kbd>, <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Redo |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Select every system |
| <kbd>Esc</kbd> | Clear the selection |
| <kbd>Del</kbd>, <kbd>Backspace</kbd> | Delete or cut what is selected |
| <kbd>Shift</kbd>+arrow | Nudge the selection by 1, or 10 with <kbd>Ctrl</kbd> |
| <kbd>Ctrl</kbd>+<kbd>X</kbd>, <kbd>Ctrl</kbd>+<kbd>C</kbd>, <kbd>Ctrl</kbd>+<kbd>V</kbd> | Cut, copy or paste planets, in a save |

## Map

| Key | Does |
| --- | --- |
| <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd>, arrows | Pan while held |
| <kbd>F</kbd>, <kbd>Ctrl</kbd>+<kbd>K</kbd>, <kbd>/</kbd> | Search |
| <kbd>Home</kbd> | Fit the whole galaxy |
| <kbd>Shift</kbd>+<kbd>F</kbd> | Frame the selection |
| <kbd>1</kbd> to <kbd>9</kbd> | Switch the main layers |
| <kbd>0</kbd> | All Initializers layers, in a scenario |
| <kbd>&#96;</kbd>, <kbd>~</kbd> | All Scripts layers, in a scenario |
| <kbd>Tab</kbd> | Hide or show the dock |

## Tools

| Key | Does |
| --- | --- |
| <kbd>V</kbd>, <kbd>C</kbd>, <kbd>X</kbd> | Select, Connect lanes, Cut lanes |
| <kbd>B</kbd>, <kbd>E</kbd> | Paint systems, Erase systems, in a scenario |
| <kbd>H</kbd> | Height brush, in a save |
| <kbd>Shift</kbd>+<kbd>M</kbd> | Symmetry on or off, in a scenario |
| <kbd>[</kbd> <kbd>]</kbd> | Brush size, or nebula radius |
| <kbd>Alt</kbd> | Swap the brush while held |

## Inspector

| Key | Does |
| --- | --- |
| <kbd>I</kbd> | Issues tab |
| <kbd>Shift</kbd>+<kbd>I</kbd> | Initializer browser |
| <kbd>Alt</kbd>+<kbd>←</kbd>, <kbd>Backspace</kbd> | Back one page |

## System view

| Key | Does |
| --- | --- |
| <kbd>Enter</kbd> | Open the selected system's view |
| <kbd>M</kbd> | Open the selected system's view, or back to the galaxy |
| <kbd>Esc</kbd>, <kbd>Backspace</kbd> | Back to the galaxy |
| <kbd>Shift</kbd>+arrow | Move the open body 1° along its orbit or 1 unit out or in, or 10 with <kbd>Ctrl</kbd> |
| <kbd>2</kbd> | Orbit radii |

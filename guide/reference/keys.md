# Keyboard shortcuts

On a Mac, <kbd>Cmd</kbd> works wherever this guide says <kbd>Ctrl</kbd>,
for clicks and drags too. <kbd>Option</kbd> is <kbd>Alt</kbd>.

## File

| Key | Action |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Open screen |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>O</kbd> | Open any file |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | Save as |
| <kbd>Ctrl</kbd>+<kbd>W</kbd> | Close the file |

## Edit

| Key | Action |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Undo |
| <kbd>Ctrl</kbd>+<kbd>Y</kbd>, <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Redo |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Select every system |
| <kbd>Esc</kbd> | Clear the selection, or step back. See [What Esc does](#what-esc-does) |
| <kbd>Del</kbd> | Delete or cut what is selected |
| <kbd>Backspace</kbd> | Back one Inspector page, or out of the system view. With nowhere to go back to, the same as <kbd>Del</kbd> |
| <kbd>Shift</kbd>+arrow | Nudge the selection by 1, or 10° or 10 units with <kbd>Ctrl</kbd>. With nothing selected, pan faster |
| <kbd>Ctrl</kbd>+<kbd>X</kbd>, <kbd>Ctrl</kbd>+<kbd>C</kbd>, <kbd>Ctrl</kbd>+<kbd>V</kbd> | Cut, copy or paste planets, in a save |

## Map

| Key | Action |
| --- | --- |
| <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd>, arrows | Pan while held |
| <kbd>Shift</kbd>+<kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> | Pan three times faster while held. <kbd>Shift</kbd>+arrow does the same when nothing is selected |
| <kbd>F</kbd>, <kbd>Ctrl</kbd>+<kbd>K</kbd>, <kbd>/</kbd> | Search |
| <kbd>Home</kbd> | Fit the whole galaxy |
| <kbd>Shift</kbd>+<kbd>F</kbd> | Frame the selection |
| <kbd>1</kbd> to <kbd>9</kbd> | Switch the main layers |
| <kbd>0</kbd> | All Initializers layers, in a scenario |
| <kbd>&#96;</kbd>, <kbd>~</kbd> | All Scripts layers, in a scenario |
| <kbd>Tab</kbd> | Hide or show the dock |

## Tools

| Key | Action |
| --- | --- |
| <kbd>V</kbd>, <kbd>C</kbd>, <kbd>X</kbd> | Select, Connect lanes, Cut lanes |
| <kbd>B</kbd>, <kbd>E</kbd> | Paint systems, Erase systems, in a scenario |
| <kbd>H</kbd> | Height brush, in a save |
| <kbd>Shift</kbd>+<kbd>M</kbd> | Symmetry on or off, in a scenario |
| <kbd>[</kbd> <kbd>]</kbd> | Brush size, or nebula radius by 1 |
| <kbd>Shift</kbd>+<kbd>[</kbd> <kbd>]</kbd> | Nebula radius by 5 |
| <kbd>Alt</kbd> | While held, switches Connect and Cut, or Paint and Erase. Erase set to lanes becomes Connect. On the Height brush, Raise lowers and Ripple swaps crests and troughs |

## Inspector

| Key | Action |
| --- | --- |
| <kbd>I</kbd> | Issues tab |
| <kbd>Shift</kbd>+<kbd>I</kbd> | Initializer browser |
| <kbd>Alt</kbd>+<kbd>←</kbd>, <kbd>Backspace</kbd> | Back one page |

## System view

| Key | Action |
| --- | --- |
| <kbd>Enter</kbd> | Open the selected system's view |
| <kbd>M</kbd> | Open the selected system's view, or back to the galaxy |
| <kbd>Backspace</kbd> | Back one Inspector page, then back to the galaxy |
| <kbd>Esc</kbd> | Back to the galaxy once there is nothing else to clear. See [What Esc does](#what-esc-does) |
| <kbd>Shift</kbd>+arrow | Move the open body 1° along its orbit or 1 unit out or in, or 10° or 10 units with <kbd>Ctrl</kbd> |
| <kbd>2</kbd> | Orbit radii |

## What Esc does

Each press of <kbd>Esc</kbd> does the first of these that applies:

1. Cancels a drag.
2. Closes the initializer browser.
3. In a text field, drops what you typed.
4. Closes the Open screen or a right-click menu.
5. Switches back to the Select tool.
6. Forgets the planets you cut or copied.
7. Clears a selection of several planets in the system view.
8. Goes back one Inspector page.
9. Leaves the system view.
10. Clears the selection.

# Roadmap

These are the features planned next, roughly in order. The order can
change, and none has a date yet.

## Next for scenarios

- **Where a map lives.** Save shows whether a map goes into your own
  mod, the Paint a Galaxy mod or a plain file. A map in a Workshop mod
  or the game folder opens read-only, with Save as.
- **Move bodies in an initializer.** Open a system initializer file and
  drag its planets, moons, companion stars and belts to new orbits, or
  type exact values. The rest of the file stays as you wrote it.
- **Edit initializers in your own mod.** Add, remove, reorder and nest
  bodies, and edit a system's neighbours. A system that a mod overrides
  is previewed the way the game uses it.
- **Make initializers.** Start one from blank or from a copy of an
  existing system, edit a copy of a vanilla one, and customise one
  system of a scenario in your own mod.
- **Play a galaxy without Paint a Galaxy.** Galaxy Forge writes a small
  mod for your map with the scripts it needs. It starts as an opt-in
  preview. Paint a Galaxy maps stay supported.
- **Keep every system as it is.** Turn a save into a galaxy that keeps
  every planet, or convert a Paint a Galaxy map so it no longer needs
  the mod.
- **Edit a scenario's start.** Place colonies, deposits, fleets and
  starbases in a scenario, and they appear when a game starts on it.
- **Lay out the L-Cluster.** Place the Distant Stars L-Cluster where you
  want it on your map.

## Version 1.0

Galaxy Forge reaches 1.0 when initializer editing, galaxies without
Paint a Galaxy and editing a scenario's start are done. Until then it is
in beta.

## Ask for a feature

To ask for something that isn't listed,
[open an issue on GitHub](https://github.com/IanHeinrich/stellaris-galaxy-forge/issues)
and say what you want to do with it.

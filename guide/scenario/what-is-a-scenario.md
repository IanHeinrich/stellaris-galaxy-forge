# What a scenario is <Badge type="info" text="Scenario" />

A static galaxy scenario is a `.txt` file that a new game starts from
instead of generating a random galaxy. A save continues a campaign. A
scenario starts a new one.

- [Make a scenario](make-a-scenario.md) lists the ways to start one and
  what you can edit in it.
- [Paint a Galaxy](paint-a-galaxy.md) is the mod most maps are made for.
- [Export and play](play.md) gets your map into a new game.

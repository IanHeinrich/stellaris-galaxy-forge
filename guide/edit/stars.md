# Stars <Badge type="tip" text="Save" />

A system's star has a page of its own, like a planet.

## Change a star's type and size

Click a star in a system's Planets list to open its page. Change its
Star type and Size there.

## Change the star class of several systems

With several systems selected, the Star class action applies one class
to all of them.
